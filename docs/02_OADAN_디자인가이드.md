## 1. 브랜드 아이덴티티

### 1.1 브랜드 컨셉
| 키워드 | 의미 | 디자인 표현 |
| :--- | :--- | :--- |
| **Oasis (쉼)** | 공복은 참는 시간이 아니라 쉬어가는 시간 | 맑은 물빛 틸(Teal), 넉넉한 여백, 부드러운 곡선 |
| **Organic (자연)** | 자연식·유기농 보식, 꾸밈없는 건강함 | 세이지 그린, 샌드 베이지, 손으로 그린 듯한 일러스트 |
| **Beautiful (아름다움)** | 기록하고 자랑하고 싶은 경험 | 감성적인 인증 카드, 섬세한 마이크로 인터랙션 |

### 1.2 디자인 원칙
1. **Calm over Alarm** — 경고·빨간색·카운트다운 압박 대신 차분한 색과 '채워지는' 메타포를 사용합니다.
2. **One Glance** — 홈 화면을 여는 순간 1초 안에 "얼마나 지났고, 지금 어떤 상태인지" 알 수 있어야 합니다.
3. **Warm Guidance** — 모든 문구와 피드백은 평가하지 않고 응원합니다.
4. **Share-worthy** — 완료 화면과 인증 카드는 그대로 SNS에 올려도 아름다워야 합니다.
5. **Safe by Design** — 건강 위험 안내는 감성보다 명확성을 우선합니다.

### 1.3 브랜드 메타포 — "사막에서 오아시스로"
단식 경과에 따라 화면 비주얼이 **모래빛 사막 → 물이 차오르는 오아시스**로 변화하며, 이는 타이머·대사 단계·스트릭 전반에 일관되게 적용됩니다.

## 2. 로고

### 2.1 구성
| 요소 | 설명 |
| :--- | :--- |
| 심볼 | **물방울 + 새싹** 결합. 물방울 내부 하단에 지평선(사막)이 있고, 그 위로 새싹 잎 두 장이 솟은 형태 |
| 워드마크(국문) | `오아단` — 둥근 고딕 기반 커스텀 레터링, 'ㅇ' 두 개를 물방울 실루엣으로 변형 |
| 워드마크(영문) | `OADAN` — 기하학적 산세리프, 'O'를 심볼과 동일한 물방울로 대체 가능 |
| 조합 | 가로형(심볼 + 워드마크), 세로형, 심볼 단독(앱 아이콘·파비콘) |

### 2.2 사용 규칙
- **최소 여백:** 심볼 높이의 1/2 이상을 사방에 확보
- **최소 크기:** 심볼 단독 24dp, 가로형 80dp 너비
- **허용 색상:** Primary Teal / White(어두운 배경) / Deep Ink(단색 인쇄)
- **금지:** 비율 왜곡, 회전, 그라데이션 임의 적용, 저대비 배경 위 배치, 그림자·외곽선 추가

### 2.3 앱 아이콘
- **배경:** Oasis Teal → Teal 400 대각 그라데이션 (좌상 → 우하)
- **전경:** 흰색 물방울+새싹 심볼, Adaptive Icon 안전 영역(66dp 원) 내 배치
- **Themed Icon (Android 13+):** 단색 심볼 레이어 별도 제공

### 3.5 테마 시스템 & 다크 모드 (Night Oasis)
오아단은 사용자의 시각적 피로도를 낮추고 일관된 브랜드 경험을 유지하기 위해 3종의 테마 모드와 체계화된 ColorScheme을 지원합니다.

#### 테마 동작 정책
- **기본 모드:** ☀️ **라이트 모드 (Sand Palette) 고정** (초기 실행 시 시스템 다크 모드 설정과 무관하게 라이트 모드로 시작하여 오아단의 따뜻한 샌드 톤 브랜드 경험을 먼저 제공)
- **지원 옵션:** `LIGHT` (라이트 모드), `DARK` (다크 모드 - Night Oasis), `SYSTEM` (기기 시스템 테마 추종)
- **저장:** DataStore 기반 영구 저장 및 앱 재실행 시 즉시 복원
- **색상 혼용 방지 원칙:** 일부 화면이나 카드에 하드코딩된 색상(예: 고정 화이트 배경에 다크 텍스트가 겹치거나 그 반대 현상)이 발생하는 것을 방지하기 위해, 모든 UI 컴포넌트는 반드시 `MaterialTheme.colorScheme` 시맨틱 토큰만을 참조합니다.

### 3.6 접근성 대비 기준
- 본문 텍스트 대비 **4.5:1 이상**, 큰 텍스트(18sp+ / 14sp Bold+)·아이콘 **3:1 이상** (WCAG 2.1 AA)
- 검증 예: `#16796B` on `#FFFFFF` ≈ 5.3:1 ✅ / `#1E2A28` on `#FAF6EF` ≈ 13:1 ✅
- `Sunset Coral #E8875B` 위 텍스트는 **Deep Ink(#1E2A28)** 사용 (흰색 텍스트 금지)

## 5. 레이아웃 & 스페이싱

### 5.1 그리드 & 뷰포트 안전 영역
| 항목 | 값 | 설명 |
| :--- | :--- | :--- |
| 기준 단위 | **4dp** | 주요 간격은 8dp 배수 사용 |
| 화면 좌우 마진 | 20dp | 주요 컨테이너 기본 좌우 패딩 |
| 컬럼 | 4컬럼 / 거터 12dp (Compact), 8컬럼 (Medium 태블릿·폴드) | 반응형 그리드 |
| 최소 터치 영역 | 48 × 48dp | 모든 인터랙티브 요소(칩, 버튼, 아이콘) 최소 터치 보장 |
| 시스템 내비게이션 패딩 | `navigationBarsPadding()` | 단말기 하단 제스처 바 및 3버튼 영역과 앱 UI 중첩 원천 차단 |

#### 하단 고정 액션 버튼 배치 원칙
- **Scaffold bottomBar 분리 원칙:** 시작하기, 기록 저장하기 등 핵심 하단 액션 버튼(Bottom CTA)은 스크롤 본문과 분리하여 Scaffold의 `bottomBar` 슬롯에 전용 컨테이너(`Surface` + `navigationBarsPadding()`)로 배치합니다.
- **버튼 겹침 및 과다 공백 방지:** 스크롤 가능한 본문(`weight(1f)` + `verticalScroll`)과 하단 고정 버튼을 분리하여, 키보드 등장이나 작은 화면에서도 콘텐츠와 버튼이 겹치지 않고, 화면 하단에 불필요한 과다 여백이 생기지 않도록 최적화합니다.

### 5.2 스페이싱 토큰
| 토큰 | 값 | 용도 |
| :--- | :--- | :--- |
| `space-xs` | 4dp | 아이콘–텍스트 간격 |

## 6. 아이코노그래피 & 일러스트

### 6.1 아이콘
- **스타일:** Rounded 라인 아이콘, 선 굵기 **1.75dp**, 끝 처리 Round Cap/Join
- **그리드:** 24 × 24dp (라이브 영역 20dp), 내비게이션은 활성 시 Filled 변형
- **기본 세트:** Material Symbols Rounded (Weight 400, Grade 0) + 브랜드 커스텀 아이콘
- **브랜드 커스텀 아이콘:** 물방울(홈), 새싹 그릇(보식), 잎+연필(기록), 대사 단계 5종, 수분 컵, 오아시스 정원

### 6.2 일러스트

| 팔레트 | 브랜드 컬러 + 대사 단계 컬러만 사용 (임의 원색 금지) |
| 주요 장면 | 사막 지평선, 샘물, 야자수, 별 뜬 밤하늘, 제철 채소·곡물 |

### 6.3 사진 (보식·레시피)
- 자연광, 위에서 내려다보는 탑뷰 또는 45° 앵글
- 배경: 린넨, 원목, 세라믹 등 자연 소재 / 채도는 원본 대비 -5~10%의 차분한 톤
- 인증 카드용 필터 3종 제공: `Sand`(따뜻), `Lagoon`(시원), `Natural`(무보정)

### 6.4 단식 대기 웰니스 그래픽 (HealthyBodyIllustration)
홈 화면 단식 대기 상태(SC-10)에서 단순한 물방울(💧) 이미지를 대체하여, 공복을 통해 얻게 되는 **가볍고 건강하며 균형 잡힌 신체와 내면의 대사 활력**을 상징하는 시그니처 벡터 그래픽입니다.

```
       ╭────────────────────────────────────────╮
       │                (  머리  )              │
       │               ╱   목   ╲               │
       │           ╭──╯          ╰──╮           │  ← 유려한 어깨선 (Round Shoulder)
       │          │   )   ●    (   │           │  ← 코어 활력 펄스 오라 (2중 링)
       │           ╲ (  단전/코어 ) ╱            │  ← 슬림 웨이스트 곡선 (Cubic Bezier)
       │            │            │              │
       │           ╱              ╲             │  ← 균형 잡힌 골반·하체 실루엣
       ╰────────────────────────────────────────╯
```

| 속성 | 디자인 규격 | 구현 사양 |
| :--- | :--- | :--- |
| **컴포넌트** | `HealthyBodyIllustration` | Jetpack Compose `Canvas` 순수 벡터 렌더링 |
| **크기** | 160dp × 160dp (권장), 반응형 지원 | `canvasSize: Dp = 160.dp` |
| **외곽 실루엣** | 부드러운 큐빅 베지어 곡선으로 연결된 인체 실루엣 | 선 굵기 2.5dp, Round Join/Cap, `OasisTeal` |
| **코어 활력 오라** | 복부 중심에서 호흡하듯 잔잔하게 퍼져나가는 2중 파문 | `rememberInfiniteTransition` (주기 2,400ms) |
| **오라 모션** | 스케일 `1.0f → 1.45f`, 투명도 `0.35f → 0.0f` 페이드 | 부드러운 호흡 리듬(Sine Easing) |
| **오라 컬러** | `SpringWater #5FB8A8` (외측) + `OasisTeal #16796B` (내측) | 은은한 글로우 효과 (Dark 모드에서도 조화 유지) |
| **시각적 의미** | "공복은 몸을 비우고 본연의 가벼운 활력을 되찾는 시간" | 사용자에게 자극적이지 않은 건강한 성취감과 심리적 안정감 제공 |

### 7.4 칩 & 태그

#### 컨디션 선택 반응형 칩 (SC-30)
5개 컨디션: 😊 상쾌 / 😐 보통 / 😣 배고픔 / 🤕 두통 / 💫 어지러움

```
[세로 화면 - Portrait (폭 < 400dp)]  → 텍스트 줄바꿈 깨짐 방지: 이모지 아이콘만 1행 5열 균등 분할
┌─────────┬─────────┬─────────┬─────────┬─────────┐
│   😊    │   😐    │   😣    │   🤕    │   💫    │  (높이 50dp, weight(1f))
└─────────┴─────────┴─────────┴─────────┴─────────┘

[가로 화면 - Landscape (폭 >= 400dp)] → 아이콘 + 텍스트 병행 노출
┌──────────────┬──────────────┬──────────────┬──────────────┬──────────────┐
│  😊 상쾌     │  😐 보통     │  😣 배고픔   │  🤕 두통     │  💫 어지러움 │
└──────────────┴──────────────┴──────────────┴──────────────┴──────────────┘
```

- **반응형 규칙:** 작은 스마트폰 세로 모드에서 '어지러움' 같은 텍스트가 `어\n지\n러\n움` 형태로 비정상적으로 세로로 길어지는 결함을 방지하기 위해, **세로 모드에서는 텍스트를 생략하고 이모지만 1행 균등 배치**합니다.
- **가로 모드 및 태블릿:** 가로 공간이 충분할 경우에만 이모지와 텍스트를 함께 노출합니다.
- **안전 바텀시트 연계:** '두통(🤕)' 또는 '어지러움(💫)' 선택 시 즉시 안전 안내 바텀시트를 연계 노출합니다.
- **상태 스타일:**
  - 선택(Selected): 배경 `OasisTeal #16796B`, 테두리 1.5dp, 이모지 스케일 1.1x
  - 미선택(Unselected): 배경 `SurfaceVariant #F1EADF`, 아웃라인 0.8dp

- **혈당 친화도 칩:** 낮음(Success 계열) / 보통(Sage) / 높음(Warning 계열) — '나쁨' 같은 표현 금지

## 8. 모션 & 인터랙션

### 8.1 모션 원칙
- **흐르듯이(Fluid):** 물의 움직임처럼 부드럽고 자연스럽게
- **절제(Calm):** 단식 중 화면에는 반복·깜빡임 애니메이션 금지 (배터리·집중 방해)

### 8.2 모션 토큰
| 토큰 | 시간 | Easing | 용도 |
| :--- | :--- | :--- | :--- |
| `motion-quick` | 150ms | Standard `(0.2, 0, 0, 1)` | 버튼 Pressed, 칩 선택 |
| `motion-base` | 300ms | Emphasized Decelerate `(0.05, 0.7, 0.1, 1)` | 화면 전환, 바텀시트 등장 |
| `motion-slow` | 600ms | Emphasized `(0.2, 0, 0, 1)` | 대사 단계 전환, 수위 상승 |
| `motion-celebrate` | 1,800ms | Custom Spring | 단식 완료 연출 |

### 8.3 시그니처 인터랙션
| 순간 | 연출 |
| :--- | :--- |
| 단식 시작 | 버튼이 물방울로 변해 링 중앙에 떨어지고 링이 그려지기 시작 (600ms) |
| 대사 단계 진입 | 링 위 단계 도트가 채워지며 작은 파문(ripple) 1회 + 단계 칩 교체 + 햅틱 1회 |
| 단식 완료 | 오아시스가 가득 차고 야자수 잎이 흔들리며 빛 입자가 퍼짐 (Lottie, 1.8초, 1회) |
| 스트릭 증가 | 리포트의 오아시스 정원에 새 식물이 자라나는 애니메이션 |

- 시스템 '애니메이션 제거' 설정 시 모든 모션을 페이드(150ms)로 대체

### 8.4 시스템 뒤로가기(Back) 계층형 내비게이션 인터랙션
스마트폰 하단 물리/가상 뒤로가기 버튼 및 화면 스와이프 뒤로가기 제스처 입력 시, 사용자가 보던 작업 흐름을 잃거나 앱이 예기치 않게 백그라운드로 튕기는 현상을 원천 방지하고 예측 가능한 계층형 복귀 인터랙션을 제공합니다.

| 계층 | 상태 조건 | 뒤로가기 동작 및 피드백 인터랙션 |
| :---: | :--- | :--- |
| **1계층 (오버레이)** | 바텀시트, 팝업, 다이얼로그 노출 중 | 활성화된 오버레이를 아래로 부드럽게 슬라이드 다운/페이드 아웃(150ms)하며 닫기 |
| **2계층 (서브 화면)** | 프로토콜 설정(SC-02), 기록 작성(SC-30) 등 | 이전 부모 화면으로 복귀 |
| **3계층 (하단 탭)** | '보식', '기록', '리포트', '마이' 탭 체류 중 | 앱 종료 없이 **메인 '홈' 탭으로 즉각 복귀** (Bottom Navigation Indicator 동기 이동) |
| **4계층 (홈 루트)** | 메인 '홈' 탭 체류 중 (1차 뒤로가기) | 화면 하단에 `"뒤로 가기 버튼을 한 번 더 누르면 종료됩니다"` 스낵바/토스트 피드백 노출 |
| **4계층 (홈 루트)** | 메인 '홈' 탭 체류 중 (2초 이내 2차 뒤로가기) | 현재 타이머 상태를 보존하고 앱 정상 종료 (백그라운드 전환) |

### 9.1 홈 화면 위젯 (FR-07)
| 크기 | 구성 |

- **4×2 레이아웃 최적화 (상하 행 분리):**
  - 종료 시간 안내 문구 행과 하단 액션 버튼(`💧 +250ml`, `공복 마치기`) 행을 **상하로 분리**하여 텍스트 간격 왜곡 및 '공복 마치기' 글자 늘어짐 원천 차단.
  - 가상 프리뷰([`WidgetGuideBottomSheet.kt`](../app/src/main/java/kr/co/oadan/ui/components/WidgetGuideBottomSheet.kt)) 및 실제 런처 레이아웃([`widget_4x2.xml`](../app/src/main/res/layout/widget_4x2.xml))에 버튼 패딩(`horizontal 10~12dp`, `vertical 6dp`), `minWidth 0dp`, `minHeight 0dp`를 명시하여 기기별 파편화 방지.
- Material You **Dynamic Color 미적용** (브랜드 컬러 고정), 단 배경은 라이트/다크 자동 대응
- 분 단위 갱신 표기(`16h 24m`) — 초 단위 표시 금지 (NFR-09)
- 진행률은 **전체 목표 시간 대비 비율**로 렌더링 (16:8 외 프로토콜 100% 조기 고정 금지)

- 작은 아이콘: 단색 물방울 심볼
- 제목: `🌴 케토시스 단계 · 16h 24m` / 내용: `목표까지 1시간 35분`

```kotlin
// ui/theme/Theme.kt & Color.kt
enum class ThemeMode {
    LIGHT,  // 라이트 모드 (Sand - 기본값)
    DARK,   // 다크 모드 (Night Oasis)
    SYSTEM  // OS 시스템 다크/라이트 모드 설정 연동
}

val OasisTeal       = Color(0xFF16796B)
val SpringWater     = Color(0xFF5FB8A8)
val OrganicSage     = Color(0xFF7E9B6B)
val SunsetCoral     = Color(0xFFE8875B)
val Sand            = Color(0xFFFAF6EF)
val Dune            = Color(0xFFF1EADF)
val DeepInk         = Color(0xFF1E2A28)
val Stone           = Color(0xFF5C6663)
val Pebble          = Color(0xFFD8D1C5)

// 대사 단계
val StageDesert     = Color(0xFFE3C79A)
val StageWind       = Color(0xFFB9B98A)
val StageSpring     = Color(0xFF5FB8A8)
val StagePalm       = Color(0xFF16796B)
val StageLagoon     = Color(0xFF2F5D7C)

val OadanLightColors = lightColorScheme(
    primary = OasisTeal,
    onPrimary = Color.White,
    primaryContainer = Color(0xFFE8F5F2),
    onPrimaryContainer = Color(0xFF063530),
    secondary = OrganicSage,
    onSecondary = Color.White,
    tertiary = SunsetCoral,
    onTertiary = DeepInk,
    background = Sand,
    onBackground = DeepInk,
    surface = Color.White,
    onSurface = DeepInk,
    surfaceVariant = Dune,
    onSurfaceVariant = Stone,
    outline = Pebble,
    error = Color(0xFFC2453D),
)

val OadanDarkColors = darkColorScheme(
    primary = Color(0xFF72C1B2),
    onPrimary = Color(0xFF063530),
    primaryContainer = Color(0xFF0B4D44),
    onPrimaryContainer = Color(0xFFC6E7E0),
    secondary = Color(0xFFA5BF93),
    tertiary = Color(0xFFF2A27E),
    onTertiary = DeepInk,
    background = Color(0xFF0F1A19),
    onBackground = Color(0xFFE6EFEC),
    surface = Color(0xFF182624),
    onSurface = Color(0xFFE6EFEC),
    surfaceVariant = Color(0xFF22322F),
    onSurfaceVariant = Color(0xFFA3B1AD),
    outline = Color(0xFF3A4A47),
    error = Color(0xFFEF8A82),
)

@Composable
fun OadanTheme(
    themeMode: ThemeMode = ThemeMode.LIGHT, // 기본값 라이트 모드 고정
    content: @Composable () -> Unit
) {
    val darkTheme = when (themeMode) {
        ThemeMode.LIGHT -> false
        ThemeMode.DARK -> true
        ThemeMode.SYSTEM -> isSystemInDarkTheme()
    }
    val colorScheme = if (darkTheme) OadanDarkColors else OadanLightColors

    MaterialTheme(
        colorScheme = colorScheme,
        typography = OadanTypography,
        content = content
    )
}
```
